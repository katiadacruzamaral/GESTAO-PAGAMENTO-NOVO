# Controle de horas — impressão de horistas

Abra `index.html` no navegador. Em **Controle de horas**, selecione o período e clique em **Imprimir horas dos horistas**.

O relatório impresso apresenta, para cada horista:
- nome;
- filial de contratação;
- filial em que as horas foram trabalhadas;
- horas separadas por Turma, Monitoria e ON;
- total por filial e total do horista.

Os dados permanecem no armazenamento configurado pela aplicação.
